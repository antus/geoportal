  - A suitability node combines several normalised criteria layers with weights and returns a suitability layer.

  - The weight matrix is stored with the result and shown in its provenance.

Weighted overlay with normalisation of criteria and AHP-style pairwise comparison, with the weight
matrix saved with the result so the choice can be defended. It is the shape of almost every site
selection: plants, landfills, antennas, new offices.
