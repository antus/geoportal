acceptance:
  - A GeoFlow node that calls the sidecar (GDAL or DuckDB) runs in a process and its output is a dataset readable over WFS or WMS.
  - A GeoLibre model imported as a process runs in GeoFlow and gives the same result as in GeoLibre.
  - A file conversion previously done in the application (for example a GeoPackage to PostGIS) is performed by the sidecar with the same output.
---

GeoFlow nodes that call the GeoLibre processing sidecar (GDAL, DuckDB), the import of GeoLibre models
as processes, and the file conversions done today in the application moved to the sidecar, so that
heavy processing leaves the Geoportal JVM.
