acceptance:
  - A write node creates or replaces a PostGIS table with the features of its input, and the table holds the expected rows.
  - A publish node makes the result a GeoServer layer in the organization workspace, answering WMS GetMap and WFS GetFeature.
  - The credentials of a target server are declared on the node through a stored connection and never appear in the process document or the log.
---

The result of a chain becomes a table in a spatial database or a layer published on a map server,
with the credentials of the target server declared on the node and quotas kept along the chain. In
the new architecture the default target is the organization's own PostGIS schema and GeoServer
workspace, protected by the GeoFence rules Geoportal generates; external servers remain possible
through connections.
