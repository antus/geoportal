  - The GeoFlow palette offers an emerging hot spot node that takes point events with a date, a cell size and a time step.

  - A sample dataset of dated events shows the result on a map in the demo.

One more node in the palette: emerging hot spot analysis on a space-time cube, which says where
clusters of events are appearing, intensifying or fading over time. It makes a convincing
demonstration on any dataset of dated events.
