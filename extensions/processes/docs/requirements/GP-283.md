Next to the built-in engine, GraphHopper, Valhalla and OpenRouteService can be called as services,
and their answers compared with ours on the same input. It does not replace the built-in engine: a
closed installation has no service to call. Providers differ in units (Valhalla counts minutes and
kilometres, others seconds and metres) and the node translates them. Output properties are identical
to the built-in engine so results overlay with one legend. Licences matter if we ever embed instead
of calling: only GraphHopper (Apache 2.0) raises no question. Still open: a node that overlays two
results and shows where engines disagree, clipped to the same extent, otherwise the service always
wins because it has more roads.
