acceptance:
  - A scheduled forecast process writes, for each series, a baseline with hour-of-day and day-of-week seasonality and a short horizon with an uncertainty band.
  - The forecast is readable by charts and by the map time slider.
  - A rule "outside the expected range for this hour" raises an alert on a value that is under every fixed threshold but outside the band.
---

The plan has consumers of the forecast (the forecast horizon, the monitoring sparkline) and no producer. This computes it: a baseline with seasonality plus a short horizon, released as a process node, so it is schedulable, versioned and audited like any other chain. It also opens a rule kind thresholds cannot express: "outside the expected range for this hour", which is how a leak is seen before any fixed threshold.
