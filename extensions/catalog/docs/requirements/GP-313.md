  - '"New data" offers a CSW connector with address, protocol version, optional credentials and a connection test.'

  - Using a record that points to a WMS or WFS adds a layer that loads in a map.
  - The CSW source has an owner, tags and sharing like any other source.
---

The product can query a CSW, but only from the map's "Add layer" panel: it is not a connector, so it
does not become a source with owner, tags and sharing. This requirement brings external catalogs into the
source model: a `csw` connector (address, version, optional credentials, connection test), browsing the
records it exposes, and a "Use" gesture that turns a record into a layer. The work is not reading CSW,
which is known, but making it a source like the others. OGC API Records can follow the same path.
