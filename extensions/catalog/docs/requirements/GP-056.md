acceptance:
  - Uploading a CSV or XLSX with address columns proposes those columns as the address without the user naming them.
  - After geocoding, the page shows how many rows were matched out of the total, and the matched rows are features with point geometry in the published layer.
  - The user can correct an unmatched row by editing its address or placing it on the map, and the layer then contains it.
  - The geocoding provider is chosen in the settings of the installation.
---

On upload, Geoportal recognizes address columns in a spreadsheet, geocodes them on the server with a configurable provider, shows the match rate and lets the user fix the rows that failed. Many datasets arrive as tables of addresses rather than coordinates; without geocoding they never reach a map.
