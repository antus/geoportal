id: GP-324
title: The coordinate reference system of every source is declared and respected on every path
area: data
priority: P1
status: done
estimate: [6, 10]
legacy: R-324
acceptance:
  - A vector file and a raster stored in a projected system (for example EPSG:32632) are served at the right place by WMS and WFS.
  - A file whose reference system is unknown is refused with a message naming the problem, instead of loading at a wrong place.
---

The map engine draws in WGS84 or Web Mercator, so data stored in other systems must be reprojected before
reaching it, and the answer must be the same whatever path the data enters by: vector files, rasters, OGC
services and database tables. Each source declares its system where it is known, everything is
reprojected where the data leaves towards the map, and a layer that cannot be placed is refused with the
name of its system. Database tables become real map layers, with their geometry decoded and reprojected
on the server.

- 13 October 2026: geoportal — with data in PostGIS and published by GeoServer, reprojection is done
  by GeoServer for loaded data; external tables and services still need it. Estimate lowered from
  [12, 18] since GeoServer provides reprojection.
- 2026-10-13: in progress, phase F03 — the reference system is declared and respected on the loading path (with GP-937).
- 2026-10-13: on the loading path the system is the one the file states (crs member, srsName with its
  axis order, .prj by authority or by name, GeoPackage, GeoTIFF), else the one its format defines, else
  the one declared with `crs=` (which never replaces a stated one); otherwise the file is refused with
  the reason, and degrees that are metres are refused too. Tests tagged GP-324 cover vector files and
  rasters in EPSG:32633 landing where they belong and the refusals; the map, OGC services and database tables
  (criteria 1 to 4 beyond files) are open. Still in progress.
- 2026-10-13: with the loader sidecar the system is the one GDAL identifies as an EPSG code, else the
  declared one, else the one a CSV of latitude and longitude defines, written with `-a_srs`; otherwise
  the file is refused. Tested through the loader too. Still in progress.
- 2026-10-14: done. With the maintainer's approval, the parts that need later phases moved to GP-981
  (OGC services in a projected system on the map, F07) and GP-982 (database tables, proposed until the
  connectors of GP-957 are planned).
- 14 October 2026: belongs to `ext-catalog-geodata`, the geospatial part of the catalog (GP-983); Geoportal composes mosaikit-ext (ADR-0024).
