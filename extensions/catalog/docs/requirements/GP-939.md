title: A server-side proxy reaches services that refuse cross-origin calls
area: interop
priority: P1
status: done
estimate: [3, 5]
legacy: R-939
decisions: [ADR-0018]
acceptance:
  - A WMS without CORS headers, with the proxy on, returns its tiles to the map through the proxy address.
  - The proxy forwards only to the address registered for that source and refuses any other target.
  - Only people allowed to use the source can call its proxy; others receive 403.
  - For a feature service behind the proxy the reference system is declared and the negotiation that the server would block is skipped.
---

For each registered source a server-side proxy reaches endpoints that do not allow calls from another
origin, which is the case of many public map services. For feature services it declares the reference
system and skips the negotiation when it would be blocked. The proxy must not become an open relay: it
forwards only to the registered address and applies the permissions of the source.
