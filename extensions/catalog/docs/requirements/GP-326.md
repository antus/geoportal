title: The reference system of a source can be declared by hand when the data omits or misstates it

acceptance:
  - A table whose geometry comes without SRID (for example through a federated query engine) is placed correctly on the map after its owner declares EPSG:32632.
  - When the data states its own system and no override is requested, the declared value does not replace it.
  - The detail of a source with a declared system says "declared by hand" next to the code, not the code alone.
---

Some sources do not say their reference system or say it wrong: a federated query engine returns
geometries as WKT without SRID, so a projected table cannot be put on a map, and nobody can tell the
product which system it is. The owner of a source can declare it by hand. It is a declared fallback: it
applies where the system is unknown (SRID 0) or where the owner states the data is wrong, and it is shown
as declared, not as if it had been read. GeoServer's "force declared" and "reproject native to declared"
policies are the natural implementation for published layers.
