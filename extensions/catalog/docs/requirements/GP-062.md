legacy: R-062
acceptance:
  - A layer bound to an Iceberg or Delta table draws the features of its current snapshot, and choosing an earlier snapshot draws those of that snapshot.
  - Filters and the view are pushed down to partition pruning, so a query on one partition reads only that partition's files.
  - A schema change in the table is shown on the source and does not break the layer when the geometry column is unchanged.
---

Geoportal understands a versioned table format, Iceberg or Delta: its snapshots, its partitions and the evolution of its schema, with the geometry column mapped and filters pushed down, so a table of billions of rows can be a layer source without being copied. The reading engine comes from the federated connection (GP-175) and the embedded engine (GP-176); what remains here is understanding a table that has a history.
