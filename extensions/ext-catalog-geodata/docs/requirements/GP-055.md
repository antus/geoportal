acceptance:
  - A COG in a registered S3-compatible bucket is drawn on a map through HTTP range requests, and no copy of the file appears in the storage of the organization.
  - A PMTiles or GeoParquet file in the bucket becomes a layer that draws its features.
  - A spreadsheet in a connected shared folder can be added as a data source and shows its rows.
---

An organization registers an S3-compatible, Azure or Google bucket and reads cloud-native files (COG, PMTiles, GeoParquet, Zarr) from there without copying them into Geoportal; and a shared folder such as Google Drive covers the ordinary case of spreadsheets and files kept by a team. Mosaikit provides the file store and the connector framework for external file services; Geoportal adds what turns a file there into a layer or a source: reading the format, ranges, footprint and metadata, and rendering.
