  - The sheet contains schema.org Dataset structured data that a structured-data validator accepts.

The public sheet shows the RNDT metadata collected by the metadata editor (they are shown here, not defined a second time) and lives on a permanent address that does not change when the resource is renamed, because it is the address that ends up in official acts. With it come structured data for search engines: a geoportal that does not show up when searching for the name of its dataset gets republished elsewhere.
