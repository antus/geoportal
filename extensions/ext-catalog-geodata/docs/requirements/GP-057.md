  - After an upload the report states the recognized format, the coordinate reference system, the number of features, the number of invalid geometries and the type of each attribute.
  - A file with invalid geometries offers a repair action, after which the published layer contains only valid geometries.
  - A file without a declared reference system is reported as such instead of being published with a guessed one.

One report per upload: the recognized format, the reference system, the number of geometries, the invalid geometries and the types of the attributes, with a corrective action where one exists (repair geometries, declare the reference system, change an attribute type). In the new architecture uploads go through the GeoServer Importer or direct PostGIS writes, so the report is built from what the importer and PostGIS say about the data. Showing the geometry type (GP-276) is its first slice.
