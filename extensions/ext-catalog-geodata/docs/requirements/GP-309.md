  - A raster layer with an area rule is clipped to that area in the images GeoServer returns to the subject.
  - Adding a rule on an external service that cannot apply it makes the layer unavailable to the subject, with a message saying why.
---

A rule that applies only where someone remembered to call it is not a rule. Data rules apply where
data leaves the system: the layer served to the map (a filter and a clip for vectors, a clip for
rasters, applied by GeoServer through GeoFence), the dashboard panel that queries the source itself,
and the input of a process, where a filtered dataset could otherwise leave whole through an export.
Where the filter cannot be applied, such as a third-party service proxied by the gateway, the rule
denies and says so: a protection that silently gives up on the hard case is worse than none.
