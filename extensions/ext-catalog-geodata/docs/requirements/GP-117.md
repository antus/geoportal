  - A categorised Geoportal style published to GeoServer renders in a WMS GetMap with the same classes and colours as on the Geoportal map.
  - An SLD read from GeoServer becomes a Geoportal style that draws the same classes on the map.
  - A style property that has no equivalent in the other language is listed to the person before publishing, not silently dropped.
---

Translate between the Geoportal style grammar and the style language of the map server (SLD/SE, and the GeoServer extensions where needed), in both directions, declaring what cannot be expressed instead of dropping it silently. It feeds the publishing flow, the import of desktop projects and the style translator of the GeoLibre plugin.
