The list of data the organization declared public, browsable without an account: search, filters and resource sheet. It is not the Data page with authentication removed but a view of its own, served by endpoints that answer only on the public subset, because filtering in the interface a list the server already delivered whole is the classic way to publish by mistake. Public endpoints are new and narrow: they do not accept an arbitrary id and do not ask the permission resolver to say no, they say no by construction. Without a public resource the catalog is an empty list that does not appear in the menu.
