The public catalog gets harvested instead of browsed by hand: DCAT-AP_IT for the national aggregator, next to the CSW and OGC API Records already given by pycsw on the same list. It costs little more than a mapping of fields because the metadata are already collected; it turns "we have a catalog" into "our data are found from outside", and tenders name it by its standard.
