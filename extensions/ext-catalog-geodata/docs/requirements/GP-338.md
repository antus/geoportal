The dataset page carries RNDT-profile metadata: the fields a person fills (title, abstract, INSPIRE
theme, category, thesaurus keywords, responsible parties, constraints, lineage, resolution) and the
ones Geoportal derives itself (identifiers, reference system, extent, format, online resource). The
iPA code and the defaults of the organization are set in the organization configuration. pycsw
publishes the records over CSW and OGC API Records for harvesting by the national catalog; whether a
record goes to the public catalog is the owner's choice and does not open the data.
