id: GP-321
title: The extent of a data source is computed when it is loaded
area: data
priority: P2
status: done
estimate: [2, 4]
legacy: R-321
acceptance:
  - After uploading a vector file the catalog answer for that source includes its bounding box in WGS84 degrees.
  - A source whose extent cannot be computed reliably reports no bounding box rather than a wrong one.
---

A source knows how many features it has and of which geometry, but not **where** it is. Without the
extent, a map built from a freshly loaded source opens on the whole world and jumps when the data arrive,
and layers that are never loaded in full have no extent to use at all. The extent is computed where the
data is read, stored with the source in WGS84 and used wherever a view is created. It is computed only
where it can be done correctly.
