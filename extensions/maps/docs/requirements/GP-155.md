A layer styled in QGIS should arrive styled. Geoportal reads QML (both QGIS encodings) and SLD 1.0 /
SE 1.1 and translates them into the style grammar: single, categorized and graduated symbols, labels
with halo, layer opacity, external graphics and titles. Imported breaks carry a "manual" method.
What cannot be translated is reported, not silently dropped.

## History

- geoportal-legacy: done in v1.4.0, wave 2. QML in both QGIS encodings (single, categorized,
  graduated, simple label with halo, layer opacity; millimetres to pixels at 96 dpi) and SLD 1.0 /
  SE 1.1 (polygon, line, point and text symbolizers, equality filters to categories, ranges to
  classes, external graphics, titles).
- 13 October 2026: geoportal — still wanted; the cheapest way to inherit existing cartography, and
  the counterpart of the style export to GeoServer.
