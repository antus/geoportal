The style of a layer is a documented JSON document, not the internal state of an editor: blocks
type, config, style, label and legend, expressions and values driven by data, with one rule (where
there is a field, the value comes from the data). The visual editor is a facade over it. Changing
the type keeps what has the same meaning in the new type. Because it is portable, a style can be
copied between layers, maps and installations, and translated to the map engine and to SLD.
