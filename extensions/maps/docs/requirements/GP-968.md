Two complete themes, switchable in one click and remembered between sessions, are provided by Mosaikit. What remains for Geoportal is that each map can declare its default theme, so that a public map designed on dark looks as designed to a reader without a preference.

- 13 October 2026: geoportal — the theme choice is MK-027; only the per-map default theme is ported.
