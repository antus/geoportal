  - The filter panel offers text, number, date and list filters on the fields of a layer, and the GeoServer requests of the layer carry the resulting CQL filter.
  - Choosing a value in one filter restricts the values offered by the following filters.
  - Value drop-downs offer search and paging on fields with many distinct values.
  - On a layer whose service has a time dimension, the date filter sets the TIME parameter of the requests.

One panel for filters by text, number, date and list, where each choice narrows the values of the
next ones, with search and paging inside the value drop-downs, and a time filter that uses the time
dimension of services that have one. It is a baseline of map exploration, rebuilt in the Geoportal
plugin of GeoLibre on top of GeoServer layers.
