title: The author switches between editor and reader view in place, without saving and reopening
area: maps
priority: P1
status: proposed
estimate: [4, 6]
legacy: R-022
acceptance:
  - Switching an open map with unsaved changes to view mode shows the reader's frame with the same camera and the changes still present.
  - Switching back to editor mode restores the author's tools and the unsaved changes; nothing is reloaded.
  - The address of the page reflects the current mode, so reloading opens the same mode.
  - The switch is shown only to people who can edit the map.
---

The author needs to see what a reader will see without the save-and-reopen round trip, which also makes the published behaviour obvious. An Editor / View switch in the header of the map (and of dashboards) changes mode in place: unsaved changes and the framing stay. The address follows the mode, the switch appears only to people who can edit, and extensions of the map can react to the mode change to draw themselves differently.

## History

- geoportal-legacy: done in v1.4.0, wave 1. The switch was added to the builder header with an event for plugins that render differently in the two modes.
- 13 October 2026: geoportal — rebuilt on the GeoLibre-based map editor, with the mode passed through the embedding and the Geoportal plugin.
