A map is read either as a globe, for 3D data and terrain, or as a flat map, for thematic work. The
viewer switches between the two from one control, keeping the position, and offers the scene panel:
navigation controls, saved positions, a coordinate bar and a loading indicator.

## History

- geoportal-legacy: done before v1.2.0 (already in the product when the plan was written), wave 0.
  Globe, flat map and Columbus view with an animated transition, plus the scene panel (controls,
  positions, coordinate bar, loading indicator).
- 13 October 2026: geoportal — still wanted; GeoLibre offers 2D (MapLibre) and 3D (Cesium) views, so
  the work is wiring and the scene panel. The legacy estimate was 0 days because the feature already
  existed; the estimate is the cost of rebuilding it.
