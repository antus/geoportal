acceptance:
  - In view mode the map tool bar shows layers, basemap, tools, scene, terrain, controls and image, and no author items (control placement, author filters, save) exist in the page.
  - In view mode the reader can switch controls on and off, choose terrain and basemap and change opacity, but sees no delete or drag handles and no service tokens.
  - A dashboard in standalone view with no allowed items shows no tool bar at all.
---

Builder and viewer used to be two different frames for the same map, so a reader received a poorer product than the one the author built. The icon bar becomes the bar of the map in both modes; each item declares whether it is content (always) or author-only, and author items do not appear in view mode instead of appearing disabled. Inside shared panels, what composes the map stays the author's (service tokens, projection, control positions, add zones), while the reader can still use what changes only the view.

## History

- geoportal-legacy: done in v1.4.0, wave 2. The bar became a declared table of items with a section each (content or author); a second pass gave the reader scene, terrain and controls in a reduced form.
- 13 October 2026: geoportal — the same rule is applied to the GeoLibre-based map frame through the Geoportal plugin and the embedding mode.
