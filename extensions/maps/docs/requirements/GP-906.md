The map supports ten layer types, each with the properties of its kind (opacity, order, visibility),
choosing the layers of a service from its capabilities. In the new architecture GeoLibre draws most of
these natively; Geoportal's part is mapping each catalog source type to a GeoLibre layer in the catalog
source plugin, saving those properties with the map, and covering what GeoLibre lacks (CZML, stream and
database layers through the real-time layer and GeoServer).
