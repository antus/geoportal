The base of the style editor: a visual menu of symbol types per geometry (for points marker, circle,
icon, text, 3D model; for lines simple, dashed, wall, path; for polygons filled, extruded), a live
preview of the symbol, a style per geometry on layers that mix geometries, binding of any style
property to an attribute, and graduated or categorized styles with generated classes and palettes.

## History

- geoportal-legacy: done before v1.2.0 (already in the product when the plan was written), wave 0.
  Live symbol preview and a visual menu of types for points, lines and polygons (some specific to
  the legacy engine), style per geometry on mixed layers, binding of a style property to an
  attribute, graduated and categorized styles.
- 13 October 2026: geoportal — still wanted; the list of types is redrawn on what MapLibre and
  deck.gl draw, not on the legacy engine's catalog. The legacy estimate was 0 days because the
  feature already existed; the estimate is the cost of rebuilding it.
- 2026-10-15: in progress.
- 2026-10-15: done. The style editor of the publishing dialog of ext-catalog-geodata, the one that exists
  today: a menu of the symbol types of each geometry that MapLibre and the SLD both draw (six point
  shapes; solid, dashed and dotted lines; filled or outline polygons), a style per geometry on mixed
  layers, any property (and the colour and size of the label) bound to an attribute by category, by
  classes of values (equal intervals or quantiles) or proportionally, with classes generated from the
  values the geodata database gives and colours from a palette, written as categories, graduated and
  scaled values of geoportal/style/v1 (web/style-themes.js, load/DatasetValues.java). The live preview
  draws the symbol of each geometry and a preview map of up to 1000 features of the dataset with the
  style, redrawn at each change, as is the SLD; the map of GeoLibre (GP-340) draws the same documents with
  toMapLibre. Proved by tests/symbology.spec.ts on GeoServer, tests/symbology.test.ts and
  DatasetValuesTest (PostGIS). Icons, 3D models, walls, paths and extrusions are not in the grammar yet:
  they come with the deck.gl layers of the maps.
