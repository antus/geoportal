Small inputs should not travel to the server. An existing WebAssembly geoprocessing package is
wrapped to expose thirty to fifty everyday tools (buffer, clip, dissolve, zonal statistics, slope)
that run locally. They appear in the same tools panel and history as server tools. GeoLibre already
runs client-side processing; the work is first to reuse what it offers and add what is missing.
