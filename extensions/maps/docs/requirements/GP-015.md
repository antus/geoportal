Cartography uses hatching to tell classes apart, also in black-and-white print. Hatching is a
property of the polygon fill, not a new type: pattern (lines, cross-hatch, dots), angle, spacing,
thickness, colour and background. The SLD names shape://slash, backslash, times, horline, vertline
and dot translate one to one into these parameters on import.
