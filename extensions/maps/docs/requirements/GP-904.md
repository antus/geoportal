title: The token of the 3D asset service is set per organization and can be overridden per map
area: maps
priority: P3
status: proposed
estimate: [1, 2]
legacy: R-904
acceptance:
  - A 3D map of an organization with a token set loads terrain and 3D assets from the asset service without any token in the map.
  - A map with its own token uses that token instead of the organization's, as seen in the requests of the engine.
  - The organization token is never returned to people who are not organization managers.
---

The access token of the 3D asset service (terrain, 3D tiles) is a property of the organization, set
once for all its people; a single map can override it with its own. The Geoportal plugin passes the
token to the Cesium view of GeoLibre.
