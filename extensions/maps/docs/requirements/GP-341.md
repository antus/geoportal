The plugin inside GeoLibre that bridges it to Geoportal: the Geoportal catalog as a source of
layers, saving as a Geoportal map, layers answering 403 shown as reserved, a real-time layer for
Kafka, MQTT and SSE, a translator of the existing styles, and the GeoFlow tools. New maps are created
on GeoLibre.
