Besides the curated palettes, the author of a map can compose a ramp: two colours or more, added,
changed, reordered and reversed, with a live preview. A ramp is a list of colours written in the
style, so it travels with the map and does not depend on a shared library. It allows diverging
scales around a threshold, which two end colours cannot express.

## History

- geoportal-legacy: done in v1.4.0, wave 2. A ramp is a list of two to eight colours stored in the
  style, with an editor (add, move, reverse) for graduated styles and density; the palette menu of
  classes removed.
- 13 October 2026: geoportal — still wanted; part of the style editor of the maps extension.
