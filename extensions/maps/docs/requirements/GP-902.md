Every map starts from a basemap. The viewer offers a set of street, satellite, dark and light
basemaps chosen from a visual picker with a real preview, plus custom tile sources (XYZ, WMTS, WMS)
that an organization adds. In 3D it offers global terrain and own elevation sources, with the
elevation of a clicked point.

## History

- geoportal-legacy: done before v1.2.0 (already in the product when the plan was written), wave 0.
  Nineteen basemaps with thumbnails, custom tile sources, global terrain and own elevation sources,
  elevation at a point.
- 13 October 2026: geoportal — still wanted; basemaps and terrain become a configurable list of the
  maps extension, used by GeoLibre. The legacy estimate was 0 days because the feature already
  existed; the estimate is the cost of rebuilding it.
