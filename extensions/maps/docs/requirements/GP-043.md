acceptance:
  - A person without an account who opens a link that allows comments can add a comment on the map, and it appears to others only after the owner approves it when moderation is on.
  - A link without the comment permission shows existing approved comments but refuses new ones.
  - An administrator who turns off public comments for the organization makes the API refuse anonymous comments on every link.
---

A public link can allow comments from people without an account, anonymous or invited, so that
consultations on a plan or a map can collect remarks. The owner moderates them, and an organization
can turn public comments off entirely.
