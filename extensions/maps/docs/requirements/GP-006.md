The layer list should say what each layer looks like without opening anything: a strip for a
graduated style, chips for a categorized one, a single sample for a simple style, and for a
map-server layer a scaled GetLegendGraphic image on a transparent background.

- geoportal-legacy: done in v1.2.1, wave 1. One miniature per layer card: the ramp of a graduated
  style, the colours of the categories and, for WMS, a small GetLegendGraphic.
