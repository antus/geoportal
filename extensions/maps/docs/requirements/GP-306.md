title: Features of image layers are highlighted with their geometry when the server returns it
area: maps

acceptance:
  - Clicking a GeoServer WMS layer draws the outline of the clicked feature from the GetFeatureInfo geometry.
  - With a server that answers only in GML, the geometry is drawn in the right place for EPSG:4326, CRS:84 and a projected system.
  - With a server that returns no geometry, a dashed window is drawn and the popup states that it is the queried area.
---

A WMS answers a click with attributes but no mark on the map, which is where highlighting is needed
most. The click on WMS, WMTS and third-party image layers asks for the geometry with the attributes,
in GeoJSON where the server offers it and GML otherwise, draws it over the raster with the highlight
style and removes it when the selection changes. Where the server cannot give the geometry, the
queried window is drawn dashed and the popup says it is the queried area, not the outline of the
object.
