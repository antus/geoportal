Geoportal is extended in four places: dashboard widgets, process nodes, connectors to sources, and tools of the map. The first three are contracts of the common extensions (EXT-065), which Geoportal implements for its geospatial widgets, nodes and connectors. The tools of the map stay here: each declared, not inferred by reading the code of `ext-maps` (identifier, lifecycle, toolbar group, whether it opens a panel, a menu or a button, badge, shortcut, state), as an extension point of `ext-maps`.

## History

- geoportal-legacy: in progress, wave 4. The structural part was done in the old code (one folder for built-in plugins, sources out of runtime data); the declarative contract was still missing.
- 13 October 2026: geoportal — manifests, lifecycle and extensions extending extensions are Mosaikit's (MK-005, MK-020); what remains is defining Geoportal's four extension points and their declaration schema.
- 14 October 2026: split — the contract of dashboard widgets, process nodes and connectors is EXT-065 in mosaikit-ext; the contract of map tools stays here (ADR-0024).
