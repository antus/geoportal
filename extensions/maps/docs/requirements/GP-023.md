The attribute table must become a table one works on, not a list one looks at, and it is the prerequisite of the editing session. It needs sorting and filtering per column, a search across all visible columns (sent to the server for paged layers), formatting by type with a careful detection (numbers, dates, booleans), column widths remembered per layer, and a keyboard shortcut to open it. Columns empty on every row start hidden with a note saying how many rows were checked. The column chooser has two levels: "now" for the viewer, "for the reader" for the author, saved with the map. The table takes a sensible share of the window and remembers its height. Export and editing are separate requirements.
