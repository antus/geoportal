acceptance:
  - Opening "Add layer" in the map editor shows the catalog sources as cards, with Type and Tags filters, and the parts of the chosen source to tick.
  - The Type filter does not offer types that a map cannot draw (for example processing services).
  - Layers already in the map are shown ticked and disabled instead of disappearing.
  - The "New data" command at the top opens the three-step creation path and, when finished, the new source is selectable without leaving the map.
---

Inside the map editor (GeoLibre, through the Geoportal catalog source plugin), adding a layer looks like
the catalog page minus editing: filters, sources as cards, parts to tick. The Type list is filtered by
context, because a filter that cannot produce results is worse than none. "New data" sits at the top
and opens the creation path, so someone who notices a missing source does not leave the map. What is
already in the map stays visible and disabled. The panel adapts to its width (three, two or one column).
