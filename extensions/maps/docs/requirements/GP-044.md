Real-time co-editing of a map on the relay model: the relay holds the authoritative snapshot of the
project, the last writer wins on a delayed save, participants see cursors and viewport rectangles,
and a session code opens it in view-only or co-editing mode with an override per participant. The
limit is stated, not hidden: two simultaneous edits of the same object lose one. The relay is
GeoLibre's; Geoportal signs the identity and rights of participants and stores the result.
