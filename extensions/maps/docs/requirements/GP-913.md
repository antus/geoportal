  - A small vector layer is loaded in one request; a large one requests only the features (or vector tiles) of the current view.
  - Dense points are drawn as clusters showing their count, with outline, colour by numeric class, icon and a popup listing the grouped features.
  - Clustering settings are saved with the map and restored when it is reopened.

Small data load in one go; large data load by level of detail following the view; dense points are
grouped, with outline, colour by numeric class, icon and popup of the group. In the new architecture large
layers come from GeoServer (vector tiles or WFS by extent) and clustering is done by the map engine; the
Geoportal plugin chooses the strategy per layer and translates the cluster style.

## History

- geoportal-legacy: done in v1.2.0 or earlier, wave 0. Implemented on the level-of-detail layers of the
  old map engine.
- 13 October 2026: geoportal — rebuilt on GeoServer and GeoLibre; the legacy estimate was 0, the new one
  covers strategy choice and style translation.
