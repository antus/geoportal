  - A link with an active filter shows the same filtered features.

Transient state is encoded in the address: visible layers, filters, camera and active tool. A
colleague who opens the link sees exactly the same view without anyone saving a map. It is the
serialization on which the story map, the self-contained export and the offline viewer rest, so it
is built first, once. The shell part (an extension writing its state in the address and getting it
back after sign-in) belongs to Mosaikit.
