The time slider continues past "now": the future part is visually distinct, carries the uncertainty band and states which model produced it and when. Operations-room dashboards all sell the same thing, knowing what will happen in an hour, and without one visual convention each domain plugin would invent its own. It extends the short forecast sparkline from a single indicator to the whole map.
