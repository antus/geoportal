  - An invalid style document is refused with a message naming the faulty property.

A single panel with every option for every type confuses: a point had three basic rows and
twenty-eight under "Advanced". The style editor shows only the sections that the chosen type
declares in the style grammar, so a new visualization type is a few lines of data and not a new
panel. The header shows the legend as a live preview next to the symbol preview, and the bottom
shows the style document, editable and applicable, with an error that says why when it is invalid.
