Point maps need the icons of their domain. People upload icons, organize them in themes shared
within the organization, and pick them in the style editor, also per category of a categorized
style. The product ships a read-only default theme. Icons are stored as files of the organization,
not on the disk of the application.

## History

- geoportal-legacy: done in v1.4.0, wave 2. Icons became data files with a role and a group (theme),
  so upload, quota, workspace and sharing were reused; an API lists, moves, renames and shares them;
  the product placeholders became a read-only default theme.
- 13 October 2026: geoportal — still wanted; icons are files on the Mosaikit file service (MK-041)
  with a role and a theme kept by the maps extension.
