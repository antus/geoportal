The layer panel is a tree: groups with cascading toggles, drag-and-drop reordering that matches the
drawing order, a real thumbnail per layer (for map servers, the scaled legend on a transparent
background), an error icon with its cause when a service does not answer, a quick filter by type and
visibility, and a menu on every layer and group.
