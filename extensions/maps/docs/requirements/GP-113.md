  - After caching an area, the map opens with the network off and shows tiles and vector layers inside that area.

  - Editing actions are disabled while offline.

Field work happens where the network does not. On top of the installable shell, a person chooses an
area and a map, and the viewer caches its tiles and vector data for that area, so the map opens
read-only without network.
