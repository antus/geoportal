A GeoLibre plugin, written on CesiumJS, that provides the 3D measurements the maps need (distances,
areas, heights on terrain and 3D tiles), limited to the analyses actually used. The legacy part about
migrating the remaining maps and removing the previous 3D engine has no object in the new product.

## History

- geoportal-legacy: to do, wave 4. It also covered migrating the remaining maps and removing the
  previous 3D engine and every reference to it.
- 13 October 2026: geoportal — the 3D measurements are still wanted on GeoLibre; the engine removal
  is dropped because nothing of it is carried over, so the estimate is reduced.
