Hexagon aggregation shows where points concentrate without the clutter of the points themselves.
Points are counted, or an attribute summed, into hexagons at a fixed resolution or one that follows
the zoom, and cells are coloured with the graduated classification and the ramps of the style
editor. Computing cells and drawing them stay separate, so that cells computed in the database by a
grouped query can be drawn the same way.

## History

- geoportal-legacy: done in v1.4.0, wave 2. Hexbin as a companion layer sharing the point store of
  the heatmap; cell computation kept separate from drawing (cells as a list of {lng, lat, value,
  count}) so that a later grid index can pass cells computed by a GROUP BY.
- 13 October 2026: geoportal — still wanted; deck.gl offers hexagon aggregation, and for large
  layers the cells should come from PostGIS.
