Four small actions that save time every day: zoom to the extent of a layer from its card; copy the
style of a layer and paste it on another, adapting it when the geometry differs; copy the style as a
JSON document to the system clipboard; and remember the width of the side panels between sessions
and between the map and dashboard builders.

## History

- geoportal-legacy: done in v1.4.0, wave 2. The four pieces already existed through other
  requirements (zoom from the layer actions with the bbox for WMS without capabilities, copy/paste
  of the style, style document in the clipboard and in the style panel, panel width remembered
  across builders).
- 13 October 2026: geoportal — still wanted; small features to rebuild in the layer panel of the
  maps extension.
