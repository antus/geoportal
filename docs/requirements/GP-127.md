A guide in English for developers who extend Geoportal, a reference generated from the declaration schema and the typed context (so it cannot drift from the code), and three complete examples: a sensor widget, a GeoFlow process node and a REST connector. Generic extension development (packaging, signing, backend, tests) is documented by Mosaikit and linked, not repeated.
