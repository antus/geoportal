  - A script node runs the code written in it on its input features and returns its output to the next node, within a time and memory limit.
  - An extension that contributes a node to the processes extension makes it appear in the palette and in the map tools panel after installation, with no change to Geoportal.
  - A contributed node runs on the server like built-in nodes and its runs appear in the run history.
---

A node can be a script, and new nodes are added as process plugins without touching the product. In
the new architecture a custom node is an extension extending the processes extension through an
extension point (MK-020), bringing its manifest, its dialog and its Java executor. Script nodes need
limits on time and memory so a script cannot take the server down.
