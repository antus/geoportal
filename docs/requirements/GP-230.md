acceptance:
  - A model view saved with section, storey and isolation can be added as a dashboard panel and opens in that state.
  - The same view embeds in a third-party web page with a snippet and shows the saved state, not the default view.
  - The embedded view respects the permissions of the model; a private model does not render for an anonymous visitor.
---

The model view inside a dashboard and inside a third-party page, on the same bridge the map panel uses,
with the saved view (section, storey, isolation) instead of the default one. It is the surface through
which a model reaches people who will never open the map builder.
