Starting from a template is faster than starting from nothing. Each builder offers a gallery of
starter templates. Before saving, the builder validates the resource and marks each faulty item.
Leaving a builder with unsaved changes asks for confirmation; the shell provides that guard for
every extension.

## History

- geoportal-legacy: done before v1.2.0 (already in the product when the plan was written), wave 0.
  Template galleries for maps, dashboards and processes, validation before saving with a mark per
  item, confirmation before leaving unsaved changes.
- 13 October 2026: split — the galleries and the validation are Geoportal's; asking for confirmation
  before leaving a page with unsaved changes is a generic shell feature (MK-106).
  The legacy estimate was 0 days because the feature already existed; the estimate is the cost of
  rebuilding it.
