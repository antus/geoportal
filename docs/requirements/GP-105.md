acceptance:
  - Each model used by the AI nodes appears in the registry with version, input requirements, cost per unit and licence.
  - A node refuses an input that does not meet the requirements of its model, before calling it.
  - A run records the model and version it used.
---

Models become catalog entries with version, input requirement (bands, resolution), cost per unit and
licence, in the same shape the extension registry uses. It is what lets a score be traced back to the
model that produced it.
