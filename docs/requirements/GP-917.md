A dashboard widget reads from nine source kinds: static data, authenticated REST, direct SQL, feature service, processing service, WebSocket, SSE, Kafka and MQTT, besides the ready-made live sources. Streaming sources go through the backend and the gateway, so credentials stay on the server.
