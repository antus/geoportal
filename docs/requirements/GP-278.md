  - A scatter widget on a dataset with lat/lon key fields uses them as axes.
  - An axis chosen by hand is kept after reloading the dashboard.
---

The catalog declares, for each dataset, which column is the date, the value, the label, the
identifier and the coordinates. A widget bound to a dataset, whether picked by hand, created from a
template or duplicated, uses those key fields on every load, so its chart is never empty; latitude
and longitude become the axes of a scatter chart only. A choice already made by the author is never
overwritten.
