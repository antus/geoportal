The cold archive and the cloud-native formats produce columnar files that nobody reads back: raw telemetry is written and stays there. An engine reads Parquet and GeoParquet where they are, in storage or in a registered bucket, and exposes them as layer and dashboard sources with the same shape as the others. It runs embedded (a library such as DuckDB), not as a cluster, because the portable distribution is a product constraint. With it, the history of real-time streams becomes queryable.
