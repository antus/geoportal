An editor with schema completion, a preview of the result and one click to promote the result to a map layer or to a dashboard source; queries are saved per organization. Queries on connected sources run on the server; queries on layers already in the map run in the browser on DuckDB-WASM (which GeoLibre already embeds): two engines, one surface. Natural-language to SQL is a separate requirement on top of this editor.
