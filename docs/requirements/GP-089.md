acceptance:
  - A device registered on a network shows its identity, position, capabilities, health and the time and content of its last message.
  - A device whose position is inherited from a feature of a dataset is drawn at that feature, and moves if the feature is edited.
  - A device of a mobile network takes its position from the payload, one marker per device key.
  - A device that stops sending changes health to silent after the network's expected interval.
---

Between a connection and a map layer there is today no object that is the sensor, so a network stays a list of passing rows. Three entities fill the gap: the network (pointing to an existing connection, so no second set of credentials or health check), the device and the observation. A device position is fixed on its record, mobile from the payload, or inherited from a feature of a dataset (manhole, pole, substation), which utilities use most. The registry stays minimal (identity, health, link to geometry, retention); acquisition is done by the supported brokers. External IoT systems are presets over MQTT and REST, not connectors to maintain one by one. The live layer is the existing one, bound to a network, its symbol driven by the state of the last reading against its thresholds.
