  - The OpenAPI descriptions of Geoportal's APIs pass the checker of the Italian interoperability guidelines with no error.
  - A dataset that an organization publishes as an e-service on the national data platform answers a consumer authenticated with the prescribed security pattern, and refuses a consumer without a valid agreement.
  - The published e-service returns the same features as the WFS or OGC API Features answer of GeoServer for the same dataset.
---

The Italian technical interoperability guidelines ask for a profile of the API description (mandatory fields, error shape, naming, versioning) and security patterns for authentication between administrations; the national digital data platform is how two bodies exchange data without a hand-signed agreement. Geoportal keeps its own APIs within the profile and lets an organization publish a dataset (through its OGC services) as an e-service with its usage agreement.
