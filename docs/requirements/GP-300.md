  - The Edit command of the detail panel opens the creation form of that type, filled in, with the type fixed.
  - Saving updates the source and keeps every setting the form does not show (method, authentication, headers).
  - The card and the detail show the new values after saving, without reloading the page.
---

"Edit" opens the same form used to create the source, filled in, in two steps instead of three since the
type cannot change. The update starts from what the server returned and changes only the fields the form
shows: a body written from scratch would erase settings simply by not repeating them.

## History

- geoportal-legacy: done in v1.4.0, wave 3. Database, queue and external catalog connections still
  delegated editing to their own pages.
- 13 October 2026: geoportal — editing from the detail panel is rebuilt; in the new catalog every
  source kind should be editable there.
- 14 October 2026: moved — generic, carried on by EXT-017 in mosaikit-ext (`ext-catalog-connection`), which Geoportal composes (ADR-0024).
