At conversion time Geoportal extracts what the IFC says about each element (global id, class, name,
type, storey, system, materials, quantities, property sets) into an indexed table. This is the item the
whole BIM area rests on: filters, attribute table, thematic styling, quantity take-off, dashboards,
external links and global search are all reads of this table, and none of them has to be built twice.
There is one table per organization keyed by model, revision and element (not one table per model);
properties live in a document per element, and the fields used for filtering and grouping are indexed as
the BIM-to-GIS dictionary (GP-214) decides. The table is created with the organization's first model, so
it costs nothing to those without models.
