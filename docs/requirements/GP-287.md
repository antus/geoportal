From the detail of a source, once a piece is chosen (a layer, a table, a quantity), the user creates directly what they want to do with it: a map with that layer already in, a dashboard with a sample widget bound to that data, a process with the input node already chosen. The three builders can already open on a new resource; they receive the starting data. Without a chosen piece the commands stay disabled, because a map "with thirteen layers in it" is not what was asked. The configuration passed must use the layer and node kinds the builders really know, or the result is an empty map with no error.
