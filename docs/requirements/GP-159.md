acceptance:
  - From an alert a person creates a work order with state, assignee and the geometry of the alert, and it shows on the map.
  - A rule can create one work order per feature it flags, so twelve flagged substations yield twelve work orders.
  - A rule configured for a help-desk system creates a ticket there through a signed webhook, carrying the alert and its location.
---

An alert should not end in a notification: it opens an intervention. Signed webhooks, ticket creation on common help-desk systems and a work order model with state and assignee. It is the difference between saying "twelve substations are in a flood zone" and generating twelve inspections, and it is what utilities buy.
