half a second because the page partials still contained it and the new header was built by script.

## History

- geoportal-legacy: done (release not cut), wave 3. The dead statistics row was removed and the old
  header hidden until the new one existed.
- 13 October 2026: dropped — a defect of the old page partials; the new list pages are extension
  frontends in the Mosaikit shell and have no such legacy markup.
