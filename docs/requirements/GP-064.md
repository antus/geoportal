The analyst who wants a buffer or a join now should not have to open the process builder. The map
offers a searchable list of tools, by name, category and engine, and each tool opens a dialog
generated from the same node manifest that draws the inspector of the node: one catalog, two
renderers. Running a tool builds a one-node process behind the scenes and runs it through the normal
execution path, so log, cancel and quotas come for free. In the new architecture the panel lives in
the Geoportal plugin inside GeoLibre ("GeoFlow tools") and calls the processes extension.
