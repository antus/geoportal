An estimate of the bytes before execution where the source exposes it, a limit per organization and per source, interruption with the reason when the limit is exceeded, and a log per organization with who, when, how long, how many bytes read and how many rows returned. On pay-per-use warehouses it is the first question of whoever signs the contract; without it the SQL workspace is an elegant way to spend someone else's money. The limit itself belongs to the generic quota model of the platform, like every other plan limit; Geoportal measures and enforces it on its data sources.
