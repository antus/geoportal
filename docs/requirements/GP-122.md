A developer outside the team should start a Geoportal contribution from a working example, not by copying an existing one. The Mosaikit devkit (create-mosaikit-extension) already writes a generic extension; Geoportal adds templates for its four extension points: dashboard widget, GeoFlow process node, connector and map tool, each complete with manifest, source, configuration panel, translations, test and README.
