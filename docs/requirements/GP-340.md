The read-only form of the GeoLibre viewer, embedded with `@geolibre/embed` in the maps extension, and
the dashboard map widget built on the same embedding instead of a hand-written iframe bridge. A
converter turns legacy map configurations into GeoLibre projects, so that demonstration and imported
maps open alike; visual comparisons use a real GPU renderer, because software rendering is unreliable
on terrain-clamped geometry.
