Telemetry goes one way only; actuators such as street lights and sprinklers need the platform to write back: switch on, close a valve, change the sampling rate. It closes the digital twin and is the only item that can do physical damage, so it is built with declared brakes: off by default per organization, a permission distinct from editing, a dry run, a confirmation asking for the device name, an expected acknowledgement with a deadline, no bulk send without a second approval, and an audit entry for every command. The command goes out on the network's own connection, never a second address. The switch belongs to the organization administrator.
