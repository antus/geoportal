Every kind of data source (file, OGC service, database, stream, REST endpoint) has an owner and a
description. A service is added by a person exactly like a connection, so it has an owner too. Under the
name the card shows one thing with one rule: the description, or, when missing, the address, which for a
service is what identifies it. The description field sits right under the name in every form and can be
cleared.
