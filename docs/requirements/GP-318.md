acceptance:
  - Dropping a file on the catalog list or on the source picker starts its upload, with a drop overlay shown only while a file is dragged.
  - The notice of a completed upload offers "Open it in a map" only when the data can be drawn on a map, and that action opens a map with the layer framed.
  - For a file, the creation path offers "Create" on the second step, with "Add details" as a secondary action.
---

The most common case is a file on one's own disk, and it cost nine gestures from the data page against
three from the map editor. Dropping a file is accepted where one arrives (the catalog list and the
picker); the upload notice offers "Open it in a map" when the type can be drawn; and "Create" is available
on the second step since the third has no mandatory questions. The map is framed on the extent from the
start (see GP-321).
