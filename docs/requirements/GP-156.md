An index of layers, fields, metadata and analyses already made, queried by the assistant before it
writes a query. Without it the assistant knows only the open map; with it, it knows the
organization's holdings and stops asking for what is already written. The retrieval mechanism for
the assistant (an index fed by extensions, filtered by the rights of the person) is generic; feeding
it with the catalog, RNDT metadata and analysis provenance is Geoportal's.
