Every panel that has nothing to show says what it is about, what happened, why, and what to do, with an illustration and a button. It distinguishes the causes: nothing created yet (offer to create), filters exclude everything (offer to clear them), the service did not answer (offer to retry, with the service message under Details), offline, access denied. A failed request must never be shown as an empty list inviting to create a first item. Texts follow a language change without redrawing.

## History

- geoportal-legacy: done in v1.4.0, wave 2. One component with five kinds and three sizes replaced 67 panels, of which only one had an action before; it also fixed lists that turned a failed fetch into "nothing here".
- 13 October 2026: moved — an empty/error state component is generic and belongs in the Mosaikit UI kit; Geoportal extensions use it for their own panels.
