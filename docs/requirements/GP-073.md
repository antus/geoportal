  - In an editing session a person can select, move, add and delete features, drag vertices and extend lines on a vector layer of the organization, and the counter shows the number of pending changes.
  - Until commit, WFS answers of GeoServer for the layer and queries on its PostGIS table return the data unchanged.
  - Abandoning a session leaves the source table identical to before the session.
---

The largest functional gap: today correcting a geometry or ticking a status on a loaded dataset has
no home. An editing mode writes to a working copy: select, move, add and delete geometries, drag
vertices, extend lines. The state of the session is explicit, with a counter of pending changes.
Nothing is written to the source until commit, which is what makes it safe to give editing to every
role that has the right. In the new architecture the drawing and vertex tools are GeoLibre's; the
Geoportal plugin binds them to a layer stored in PostGIS and keeps the session in Geoportal.
