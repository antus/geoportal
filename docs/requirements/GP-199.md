The placement of a model is read from the model instead of being dragged by eye: map conversion, site
coordinates, elevation, units, project north against true north and the target reference system. When
the model does not carry them, which is common, it is placed by hand once and the transformation is
saved on the model, not on the map, so every map that uses it finds it already in place. Sample models
should include the three usual broken cases (no map conversion, millimetre units, rotated project
north), which are how a building ends up in the sea or underground.
