acceptance:
  - An element can be linked by its global id to an asset register record, a maintenance work order or a registered device.
  - The element panel shows the live value of the linked device and updates when a new observation arrives.
  - An alert rule can target an element, and its alert shows on that element in the 3D view.
---

The element identifier as a key towards an asset register, a maintenance intervention or a device of
the device registry (GP-089): the live value inside the element panel, and an alert rule that points at
an element instead of a broker topic. It closes the digital twin on the building, and is why the BIM area
belongs to the same story as sensors.
