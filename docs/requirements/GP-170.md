Email verification, invitation acceptance, forgotten and reset password were four pages with four tones. They become one shape, a message and an action, without the full application bar around a screen the visitor cannot use yet: only the brand mark, theme and language. An already-used verification link is good news, not an error; a rejected reset link offers to request a new one; every final state carries an action.

## History

- geoportal-legacy: done in v1.4.0, wave 2. The empty/error state component got a large size and was used for the four screens, with the bar reduced to brand, theme and language.
- 13 October 2026: moved — sign-in and account screens are the Mosaikit shell's (MK-047, confirmation mail MK-048); invitation and password reset screens are not explicitly covered there and should follow the same page.
