  - An Iceberg REST catalog registered as a connection lists its namespaces and tables in the catalog browser, each with schema, partitions and snapshots.
  - Choosing a table from the list creates a layer source bound to it, without typing its path.
  - A catalog that refuses the credentials shows the error it returned instead of an empty list.
---

Reading a versioned table (GP-062) is one thing; finding it is another. Iceberg REST Catalog and its equivalents (Unity, Glue, Hive Metastore) are declared once as a connection, and their tables appear in the catalog browser with schema, partitions and snapshots, like the layers of a WFS. On a lakehouse with thousands of tables, choosing from a list instead of pasting a path makes all the difference.
