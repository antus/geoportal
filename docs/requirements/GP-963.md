  - Opening a Geoportal page never starts a tour by itself.
  - The help command of the page starts the tour of that page, in the language of the person, and can be restarted at any time.
  - Each step of the map editor tour points at an element that exists on the page.
---

Each page has its own localized tour, started only from the help icon and restartable at any time, never on opening: a tour that starts by itself interrupts people who already know what to do. The tour engine is generic; the tours of the map, dashboard, process and catalog pages are Geoportal's content.

## History

- geoportal-legacy: done before v1.2.0 (already in the product when the plan started), wave 0; recorded for tracking in September 2026.
- 13 October 2026: split — the tour engine and its help command in the shell are an MK need; Geoportal writes the tours of its pages. The estimate is for the Geoportal tours.
