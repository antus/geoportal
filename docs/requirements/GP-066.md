acceptance:
  - The result of a map analysis is added to the map as a layer styled with the default style of its geometry type.
  - The layer panel shows the provenance of the result - operation, inputs, parameters, time and feature count - and it is still there after the map is saved and reopened.
  - The result is stored as a dataset of the organization and is published by GeoServer like any upload.
---

The output of an analysis becomes an ordinary layer, styled by the default styles, and stored as a
dataset of the organization like any upload, so sharing, styling, export and quota behave as they
already do. The layer carries its provenance: the operation, the inputs by identifier, the
parameters, the time, the feature count and a reference to the execution. The panel shows it and the
saved map keeps it; re-running is re-executing that record. A failed execution keeps its parameters,
says which input made it fail and never leaves a half-written layer.
