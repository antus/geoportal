  - A query with conditions on class, storey, system and properties returns the count and the list of matching elements and highlights them in 3D.
  - The selection resulting from a query can be used by the other tools (isolate, table, export).
  - Typing an element's global id or name in the global search of the shell finds the element and opens the model on it.
---

The same form as the filters of a layer, applied to elements: conditions on class, storey, system and
properties, with the count, the list, the 3D highlight and a selection reusable by other tools. It brings
lookup by identifier and by name in the global search, which is how a technician reaches an element whose
code arrived in an email; Geoportal contributes a search provider to the global search of Mosaikit.
