acceptance:
  - A query whose result exceeds the interactive row limit can be run as a job, and the page keeps working while it runs.
  - When the job ends the person receives a notification in the activity feed with a download link to a Parquet file holding all the rows.
  - The link stops working after its declared expiry, and a person without access to the source cannot use it.
---

The interactive row limit stays, because it protects the browser, not the source, but it gets a way out: the query becomes a job, the result a columnar file in storage, and a notification says when it is ready, with a link that expires. Today "more than the limit" is a dead end, and whoever reaches it leaves the product to write the query somewhere else. Geoportal runs the query and writes the file; Mosaikit provides the notifications, the file store and the time-limited download link.
