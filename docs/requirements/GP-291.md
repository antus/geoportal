The data page shows every source the organization has configured, whatever its kind, in one list with
the header, tabs and filter column shared by the other list pages (maps, dashboards, processes). The
left column filters instead of navigating: a Type list computed from the sources themselves, so it
contains only the types really present. Each source has a thumbnail, either uploaded or generated from
its name (hue and silhouette from a hash of the name), so that nine WMS do not look like nine identical
rectangles. The type is shown as a label over the image, not as a tag.
