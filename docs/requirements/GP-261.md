title: Non-visual equivalent of maps and dashboards for assistive technologies
area: compliance
priority: P2
status: proposed
depends: [GP-023]
estimate: [12, 18]
legacy: R-261
acceptance:
  - For every visible layer of a map, a keyboard-navigable table of its features is reachable, and selecting a row selects the feature on the map and the reverse.
  - A screen reader reads a text summary of the current view of the map (number of features per layer, extent, classes of the legend) that changes when the view changes.
  - Every dashboard panel offers its series as a table with the same values the chart draws.
  - Every map command (zoom, pan, layer toggle, identify) can be reached in sequence with the keyboard.
---

A map is a canvas: for assistive technology it is a silent rectangle, and no contrast fix changes that. The standard asks for an equivalent content: for each layer its keyboard-navigable table with synchronized selection, for each dashboard panel its data as a table, a text summary of what the view shows (how many features, in which extent, with which classes) and map commands reachable in sequence. The attribute table and the data behind each panel exist; this builds the path that makes them the declared alternative.
