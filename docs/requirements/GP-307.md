An organization manager decides which sections (data, maps, dashboards, processes, apps) each role,
group or person reaches, deny by default with the permission declared. The rule applies in three
places at once: the navigation hides the entry, the route is not reachable and the API answers no.
Who lands on a closed section reads why and whom to ask. The starting configuration equals what roles
grant today, so an organization that changes nothing notices nothing.
