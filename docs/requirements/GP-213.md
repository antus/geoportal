acceptance:
  - Selecting an element shows its properties grouped by property set, sorted, with quantities, layered materials and classification in their own sections.
  - Typing in the search box of the panel shows only the properties whose name or value matches.
  - Each value can be copied to the clipboard with one click.
---

Property sets grouped and sorted, quantities, layered materials, classification, with search inside the
properties and copy of a value. A flat popup of whatever the tileset carries is a list to scroll on an
element with forty properties, and the one needed is always the thirtieth. The panel reads the element
table (GP-201), so it also shows properties that the tileset does not carry.
