The input of a map analysis is something the person already sees: a layer loaded in the map, with a
selector for all features, the current selection or what is in view, or an area drawn on the map.
Tools with several inputs (network, spatial join, clip) ask one layer per port declared by the node
manifest. Selection needs a stable selection model across layers, shared with the attribute table
and editing; whoever builds it first builds it once.

## History

- geoportal-legacy: done in v1.4.0, wave 1. Input from a layer on the map with scope all / in view, or a drawn area; click selection did not exist in the product and was not invented. The panel was later extended to one input per manifest port.
- 13 October 2026: geoportal — still wanted; to be rebuilt in the Geoportal plugin inside GeoLibre, using GeoLibre's layers, selection and drawing.
- 14 October 2026: belongs to `ext-maps`, which runs the nodes of `ext-processes` (mosaikit-ext) and of `ext-processes-geodata` (GP-985) from the map; Geoportal composes mosaikit-ext (ADR-0024).
