A process starts on its own from a cron expression, or when something happens, such as a file being
uploaded. Scheduling stays in the processes extension; reacting to events of the platform (a file
added to the file service, a dataset changed) needs the backend of an extension to subscribe to
kernel events, which Mosaikit does not offer yet.
