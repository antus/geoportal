acceptance:
  - An uploaded COG is drawn on a map through range requests without conversion to another raster format.
  - A PMTiles file is served to the map and draws at every zoom level it contains.
  - A GeoParquet file can be added as a layer, and a layer can be exported as GeoParquet that GDAL reads back with the same features.
---

Geoportal reads and writes PMTiles, Cloud-Optimized GeoTIFF and GeoParquet: COGs are rendered directly, PMTiles are served from storage, GeoParquet is both a source and an export format. The new architecture already stores raster as COG; this requirement covers the other two formats and the export side.
