  - After the restore, the GeoFence rules of the organizations give the same answers to the same users as before (an allowed request is allowed, a denied one is denied).
  - The scheduled restore test records its outcome and the measured recovery time, and a failed restore raises an alert to the platform administrator.

A backup exists only when its restore is proven. The generic part (scheduled backups, periodic automated restore on a clean environment, declared recovery point and time objectives, off-site copy, written procedure) is a platform need. Geoportal adds what only it knows must travel together: the PostGIS data of the organizations, the GeoServer configuration and workspaces, the GeoFence rules and the raster stored as COG, restored consistently so that the services answer as before.
