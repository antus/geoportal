Data sources need tags like maps and dashboards have, with three kinds that look different: the
**type** (a fact: how one talks to the source, derived and not removable), the **category** (from the
catalog taxonomy, derived from the type) and the **free tag** written by a person, with the same gesture
and suggestions used when saving a map. Type and category are derived, not stored, so that the filter
columns are never empty. Types and tags are two separate filter columns, since "what kind is it" and
"what is it about" are different questions.

The generic tagging of resources (store, normalization, suggestions, filtering) belongs to Mosaikit;
Geoportal adds the derived type and category of data sources.
