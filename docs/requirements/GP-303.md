  - '"Create a map" from an uploaded file opens a map whose layer loads features, with a default symbol and the view framed on the extent of the data.'
  - '"Create a map" from a WMS opens a map whose tiles load, through the proxy when the service needs it.'
  - '"Create a dashboard" from a file or a table opens a widget that shows rows of that data.'
  - Where no working configuration is known (for example a real-time stream for a dashboard), the command says so instead of opening an empty editor.
---

The three shortcuts in the detail panel must build what the manual gesture builds; failing silently
(a map with an empty layer, a blank widget, a process node that reads nothing) looks like success and is
the worst way to fail. For a map, the layer is the one "Add layer" would produce, including the service
settings (proxy, CRS, parameters), the permission link to the source, the default symbol and label, and
the framing on the extent. For a dashboard, a data source the widget can read for that kind of source.
For a process, the input node that reads that source.
