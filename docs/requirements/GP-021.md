Panels use three text sizes and two weights, with density checked in the light and the dark theme. The old interface had 34 sizes and 7 weights, so the eye could not find the hierarchy.

## History

- geoportal-legacy: done in v1.4.0, wave 2. A type scale was declared as tokens and about 2,700 sizes and 380 weights were converted, including styles written in code.
- 13 October 2026: moved — the type ramp is part of the Fluent UI tokens wrapped by the Mosaikit UI kit (MK-026); Geoportal extensions use it instead of their own scale.
