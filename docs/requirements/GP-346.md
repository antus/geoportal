The server edition for on-premise installations: Geoportal, PostgreSQL with PostGIS and GeoServer with
GeoFence, plus Keycloak, the object store, the nginx gateway and pycsw, in images pinned to a
version. One organization by default, several on request. The `geoportal-server` distribution
already ships Geoportal, PostGIS, GeoServer (GeoFence, Importer, AuthKey) and Keycloak; what is left
is the object store, the gateway, pycsw, pinned images and the release smoke test.
