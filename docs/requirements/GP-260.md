acceptance:
  - An automated accessibility check run on the ten critical paths of Geoportal (catalog search, map viewing, map building, dashboard building, upload, process run among them) reports no WCAG 2.1 AA violation.
  - Every builder of Geoportal and every dialog it opens can be completed with the keyboard alone, and a screen reader announces the state changes (layer shown or hidden, panel opened, save done).
  - The check runs in the build of the Geoportal repository and fails the build when a fixed violation comes back.
---

Italian law and EN 301 549 ask for WCAG 2.1 AA measured, not declared. The shell is Mosaikit's; the pages, builders, dialogs and the frame of the map engine are Geoportal's, so Geoportal verifies its ten critical paths, fixes what comes out (contrast, accessible names, roles, reading order, keyboard-only use of builders and dialogs, announcement of state changes) and keeps an automated check in its build so that nothing regresses. This verification is the basis of the accessibility statement, which must not be signed without it.
