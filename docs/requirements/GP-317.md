acceptance:
  - A node whose manifest declares a field of type source shows a source row that opens the shared picker, also for third-party nodes.
  - Choosing a source in the field creates the source node on the canvas and connects it to the declared port (for example the clip area of a spatial filter).
  - Cutting that connection empties the field, and the created source node can be reused for another branch.
  - Running the process reads the chosen source through the created node.
---

Not a new node but a **field type** that nodes declare in their manifest, next to the field types the
process editor already renders, so any node needing data gets the same row and picker, plugins of third
parties included. Choosing a source in the field creates the source node and wires it: the field is a
shortcut for drawing part of the graph, not a second way to bring data in, otherwise the canvas would show
an empty port that receives data. A "Source" input in the palette covers the simple case; the protocol
nodes remain under Advanced.
