  - 'The "Send to Geoportal" command of QGIS creates a dataset with its style in the organization of the person, visible in the catalog.'
  - Opening a Geoportal map from the plugin adds its layers to the QGIS project, authenticated with the person's AuthKey.
  - A layer the person cannot see in Geoportal is not offered by the plugin.

"Send to Geoportal": from QGIS a person pushes a layer with its style to Geoportal, and brings back into QGIS the layers of a Geoportal map. Access uses the same identity and permissions as the web application (AuthKey for OWS).
