  - A tool that returns the content of a dataset caps the answer at a declared size and says it was truncated.

An assistant the customer already uses should reach Geoportal through the Model Context Protocol: search maps, dashboards, data and processes, read the metadata and a capped extract of a dataset, and run a process. The tools are adapters over the existing REST surface, never a second visibility rule: they run with the permissions of the person. Running a process has effects (quota, files, external calls), so it is an action, off by default for a token, separate from reading.

## History

- geoportal-legacy: done on 14 September 2026, not released, wave 3. A hand-written JSON-RPC server with 11 tools, personal tokens stored as SHA-256 hashes, revocation and a "can execute" switch off by default.
