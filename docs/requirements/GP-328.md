The legacy requirement moved development, tests and the portable archive from H2 to PostgreSQL with
PostGIS, with a shared development compose and one database per working tree.

## History

- geoportal-legacy: done in the legacy code (10–11 October 2026, no release), wave 3. Compose with
  PostGIS, GeoServer (GeoFence, Importer, AuthKey), gateway and Keycloak; H2 forbidden by the build;
  154 end-to-end suites compared between H2 and PostgreSQL.
- 13 October 2026: dropped — nothing remains: Mosaikit runs only on PostgreSQL, extensions are tested
  on the embedded PostgreSQL of the `@mosaikit/testing` bench (MK-050), and the `geoportal-server`
  distribution already brings PostGIS, GeoServer with GeoFence and Keycloak in Docker Compose.
