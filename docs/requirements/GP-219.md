Which elements fall in a drawn polygon or inside a section, which parcel the building stands on, how far
an element is from a network, how many elements per zone. And the other way: an element as a geometry
that a process reads together with a layer. It is the question for which a model sits on a geographic
portal rather than in a design viewer. It requires elements with georeferenced geometry in PostGIS,
derived with the placement of GP-199.
