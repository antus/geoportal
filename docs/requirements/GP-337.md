acceptance:
  - After the import, every vector dataset of the legacy installation is a PostGIS table with the same number of rows, and a GeoServer layer of the organization's workspace.
  - Rasters of the legacy installation are served by WMS as COG from the configured store.
  - A person who could not see a dataset in the legacy installation still cannot see it after the import (the GeoFence rules are in place before the layers are published).
---

Existing installations bring their files and datasets from the disk and from the old database into
PostGIS and the object store, and publish them on GeoServer with the rules already in place. It runs
once per installation and is verified by counting rows and layers before and after.
