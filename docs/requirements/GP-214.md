acceptance:
  - An organization can declare a dictionary that maps IFC classes and property set names to named fields, and reuse it across models.
  - After applying the dictionary, the mapped fields appear as ordinary fields of the model layer in filters, attribute table and dashboards.
  - Changing the dictionary updates the fields of existing models without converting them again.
---

A mapping, declared per organization and reusable, between classes and property set names of the
models and the fields Geoportal works with. It is what makes a model behave like a layer with fields, and
so what makes filters, table, dashboards and joins usable without writing code for each organization. It
relates to the element table (GP-201) as the observation decoding contract (GP-178) relates to a sensor
payload: the same idea applied to another silent source. It also decides which fields of the element
table are indexed.
