---
id: GP-060
title: Active filters and the current view are pushed down into the query of the source
area: data
priority: P2
status: proposed
estimate: [8, 12]
legacy: R-060
acceptance:
  - With a filter active on a layer from a connected database, the SQL received by the database contains the filter condition and the bounding box of the view.
  - Panning the map requests only the features of the new extent, and the number of rows transferred stays below the full table size.
  - A WFS layer with a filter sends it as a CQL or OGC filter to GeoServer rather than filtering in the browser.
---

Active filters and the current view are translated into the query of the source, so a large table is never downloaded in full. Pushing computation into the source is one of the rules of the data area: the platform does not pull a hundred million rows to count them. It reduces what is read; drawing billions of features needs tiles too (GP-188).
