One or more entries of the map history become a saved process with the same parameters, ready to be
scheduled, audited and notified. This is the strategic item of the area: an analyst experiments in
the map and turns the sequence into a governed pipeline, which competitors offering browser analysis
cannot do. Promotion emits the history records as the same process document the GeoFlow editor
saves.
