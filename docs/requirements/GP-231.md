  - Tiles of a reserved model are reachable only through signed links that expire; a tile URL without a valid signature answers 403.
  - Uploading a model beyond the organization's storage quota is refused with a clear error.
  - A map using a model from an external tiles service stores no access token; the token is kept in the encrypted credential store and sharing the map does not reveal it.

Tilesets are served by the platform from its object storage: range requests, cache validators, signed
and expiring links for reserved models, quota per organization. Signed links apply to every tile and not
only to the source file, because a tileset is a tree of files and guessing one is enough. And a fix that
comes with it: the token of an external tiles service lives in the encrypted credential store instead of
inside the saved map, because sharing a map that used such a model also shared the way to pay for it.
