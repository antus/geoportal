A federated query engine is not embedded: Geoportal talks to it. Trino offers a plain JDBC driver, so it becomes one more connection, with the same encrypted credentials, health check and query executor with its row limit; quoting and paging follow the Postgres dialect. Organizations that already have a data lake stop copying data to see it on a map: one query spans their databases and the columnar files in their buckets. Trino has no geometry type, so the geometry column is recognized by name and read as WKB or WKT.
