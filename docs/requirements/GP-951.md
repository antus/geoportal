The same release runs as a shared cloud instance, as a container stack at the customer's site, or as a
portable folder with its Java runtime included, which is copied and started. The editions are built on
the Mosaikit distributions (already in `distribution/` of the Geoportal repository); Geoportal adds its
extensions, theme and the geospatial stack (PostGIS, GeoServer with GeoFence and Importer, gateway) to
each.
