---
id: GP-216
title: Reserved model properties are withheld where the data is served
area: bim
priority: P1
status: proposed
depends: [GP-201, GP-308]
estimate: [4, 6]
legacy: R-216
acceptance:
  - A property declared reserved for a role is absent from the element API answers, the attribute table export and the tileset metadata served to a person without that role.
  - A person with the role sees the property in the element panel.
  - The same model published on the public catalog exposes none of the reserved properties.
---

Visibility rules per property and per role (costs, security devices, personal data) applied where the
data is served, never hidden in the interface: a property hidden by a style rule is a published property.
The same model goes to a technical room and to a public portal, and without this the second case cannot
be accepted. It belongs to the data rules (hidden columns, GP-308), not beside them, and the restriction
must also apply to the per-element metadata carried in the tiles.
