  - Asking the assistant to add a catalog layer, apply a style or create a filter changes the map only after the person confirms the draft.
  - The whole answer is undone with one undo, and the map returns to its previous state.
  - Each change made by the assistant appears in the audit log as made by the person through the assistant.

The assistant extends to actions that change the map: add a layer from the catalog, apply a
symbology or thematic style, create a filter. They go through the same path as a click, so they are
undoable and audited. Mosaikit's tools produce drafts the person confirms (MK-015). It must not ship
before transcript and undo exist: an assistant that changes a map in ways the person cannot see or
revert gets switched off by the first administrator who notices.
