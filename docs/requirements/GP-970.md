  - An iframe on a site that is not allowed is refused by the browser.
---

A saved map or dashboard opens in a viewer without the builder panels, with panels locked, and can
be embedded in an external web page in kiosk mode. Embedding needs the shell to serve the view
without its frame and to accept the external site, and the resource must be shared by link or
publicly.

## History

- geoportal-legacy: done before v1.2.0 (already in the product when the plan was written), wave 0.
  Read-only viewer without the builder panels, embeddable in an external page in kiosk mode.
- 13 October 2026: split — the viewer and its kiosk mode are Geoportal's; showing an extension page
  without the shell frame inside a page of another site, with link or public access, is generic
  (MK-100, MK-055). The legacy estimate was 0 days because the feature already
  existed; the estimate is the cost of rebuilding it.
