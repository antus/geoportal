acceptance:
  - Architectural, structural and MEP models added to a federation share one placement, and moving the federation moves all of them together.
  - The federation shows one element tree with the disciplines as branches.
  - Turning off a discipline hides only the elements of that discipline's model, also when another layer of the map has the same name.
---

Architectural, structural and MEP models arrive as separate files and must be seen as one building: a
group with a shared placement, a single tree and a switch per discipline. Layer grouping exists in the
map; what is added here is that the parts know they belong to the same model, so turning off the MEP
discipline is not the same as turning off a layer that happens to have that name.
