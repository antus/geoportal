The interface uses a single interactive colour; success, warning, danger and info are reserved for states, and categories use their own tokens that avoid both the accent and the state colours. Before this, three accents and sixteen hand-written state tints competed in the same panel. Charts and cartography palettes are data, not interface, and stay out of scope.

## History

- geoportal-legacy: done in v1.4.0, wave 2. Accent, state and category roles were declared as tokens and 106 hard-coded tints were converted.
- 13 October 2026: moved — the colour roles of the interface are the theme tokens of the Mosaikit UI kit on Fluent UI (MK-026); the Geoportal theme extension only supplies the values.
