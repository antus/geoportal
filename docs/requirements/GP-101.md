  - Describing a popup in words produces a popup template with the named fields and formatting, open in the popup editor before it is applied.
  - Describing a symbology (for example "graduated red by population") produces a style that GeoServer and the map render, editable in the style editor.

Describe a popup or a symbology in words and get the template, fields and formatting, then edit them
in the normal editor. The output is the same document the editors save, so nothing is hidden from the
person.
