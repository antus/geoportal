An extension declares what it needs (network hosts, storage, credentials, read access to data), the administrator sees it before installing and can deny it, and calls outside the declared hosts are blocked. The model is the same for any product built on Mosaikit; Geoportal only declares its own capabilities (for example reading layers) through it.
