  - Saving a process creates a new version; a run records the version it used, and an earlier version can be opened and restored.
  - A long asynchronous node (for example a remote WPS job) resumes after a server restart and the run completes.
  - A failed run notifies its owner in the activity feed and by e-mail, and appears in the audit log with the process, version and error.

A process has versions; long nodes run asynchronously and resume by themselves; a failure sends an
e-mail and is recorded in the audit. Versions and resumption belong to the GeoFlow executor.
Notification uses the activity feed of Mosaikit (MK-038); e-mail delivery of notifications and an
audit log that extensions can write to are generic and not yet in Mosaikit.
