  - A categorized style on class, storey, material or phase colors each element according to its value.
  - A graduated style on a quantity colors elements by class breaks, and the map legend shows the classes.
  - A style document saved from one model applies unchanged to another model with the same fields.
---

The Geoportal style grammar (GP-009) extended to tilesets: categorized on class, storey, material or
phase, graduated on a quantity, with the map legend (GP-016) and a style document that can be copied
between models. A model otherwise keeps the colors it was exported with, and there is no way to make it
say anything else. The style is translated to the 3D tiles styling of the map engine by the style
translator of the Geoportal plugin in GeoLibre.
