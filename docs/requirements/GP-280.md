Run the existing browser suites in CI against an ephemeral instance, add integration tests on real
boundaries (tenant database, broker, OGC services, model providers) with throwaway containers,
performance tests with thresholds on opening a map, uploading a file and running a process, dynamic
security tests, and one report per test kind.

## History

- geoportal-legacy: to do, wave 6. Measured coverage was 2.96%; fifty-one browser suites were never
  run automatically.
- 13 October 2026: dropped — built on the test harness of the old code base; the new extensions are
  tested on the Mosaikit test bench (MK-050). Performance thresholds on the three main paths may deserve
  a new requirement.
