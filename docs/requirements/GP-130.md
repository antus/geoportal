title: JavaScript SDK to embed and drive a Geoportal map in another web page
area: maps
priority: P2
status: proposed
estimate: [10, 15]
legacy: R-130
acceptance:
  - A page outside Geoportal that includes the SDK loads a saved public map by its identifier and shows its layers.
  - Calling the SDK to add a WMS layer of the catalog with a style makes the map request that layer from GeoServer with that style.
  - The page receives an event with the feature identifiers when a person selects features on the embedded map, and can move the camera to a given extent.
---

A documented SDK lets a third-party web page load a Geoportal map, add and style layers, listen to selection and filters and drive the camera. It formalizes the message bridge Geoportal already needs to drive the embedded map engine (GeoLibre through @geolibre/embed) and its plugin, exposing a stable, versioned subset to outsiders, with access governed by the sharing level of the map.
