Every figure the assistant writes carries the query or calculation behind it, and anything not
anchored to data is not shown at all. It is the gate that makes an assistant admissible in a public
administration instead of banned by the first reviewer, and it must be built with GP-094, not after.
Binding statements of an answer to the tool results they come from is generic and asked of Mosaikit;
Geoportal's tools return the query and the result each figure comes from.
