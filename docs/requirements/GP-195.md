acceptance:
  - A window aggregation over a live stream (for example vehicles per cell in the last five minutes) updates while messages arrive.
  - The aggregated result is usable as a dashboard source, as the input of an alert rule and as a map layer.
  - After a server restart, the window in progress is not lost and the next result includes messages received before the restart.
---

The missing piece of real time. Alert rules look at one message at a time and the archive resamples
only telemetry: nobody computes "vehicles per cell in the last five minutes" while messages arrive.
Sliding and tumbling windows run on the existing streams; the result is at once a dashboard source,
a rule input and a map layer, and the state is kept so a restart does not lose the open window.
Today a stream passes and vanishes, and a panel only knows the last value.
