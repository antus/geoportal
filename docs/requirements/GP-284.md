The Data page and the "Add layer" panel said the same things with different names. They read one list of eleven categories, declared once, that states what belongs to each: connector types, curated entries, direct URL kinds (GeoJSON, KML, CZML, 3D Tiles, GPX) and live feeds. Sources are classified by use, not technology: processing services execute rather than draw, generic REST is a transport and lives in "other sources", and ready-made live feeds have their own category. Because the map engine is now GeoLibre, the Geoportal catalog source inside it must use the same taxonomy.
