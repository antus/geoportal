A docked panel answers about what is open. On the map it describes layers and fields, runs
read-only SQL, moves the camera, turns layers on and off and filters; on a dashboard it reads the
panels, explains an indicator and changes filters; on a process it reads the graph and says why a
run failed and on which data. One panel and one contract: the context changes the set of tools, not
the interface. The assistant itself is Mosaikit's (MK-024) on tools declared by extensions (MK-015);
Geoportal declares the map, dashboard and process tools. The assistant needs to know which app and
object is open and to offer that context's tools first, which Mosaikit does not yet provide.
