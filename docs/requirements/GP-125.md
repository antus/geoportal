A contribution to Geoportal (widget, process node, connector, map tool) needs a typed context: the open map and its layers, the selection, the filters, the data sources of the catalog, plus the theme, translations, storage and HTTP that Mosaikit's SDK already gives. The context is a facade over Geoportal's internals, so Geoportal can change its code without breaking third parties. Next to it, a small package of geospatial components (layer picker, style fields, attribute chips, statistic tiles) built on the Mosaikit UI kit, so a contribution looks like the product without its own CSS.
