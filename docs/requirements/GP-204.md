  - The tree of a model shows project, site, building, storey, space and element, and a second tab shows the systems tree.
  - Selecting a node highlights its elements in the 3D view, and clicking an element in the view selects and reveals its node in the tree.
  - Isolate, hide and transparency applied to a node change only the elements under that node.
---

The decomposition tree (project, site, building, storey, space, element) plus the systems tree, which is
the other way an MEP engineer looks for a component. The tree selects in the view and the view selects in
the tree, with isolate, hide and transparency on any node. It is the panel a model is navigated with:
without it, the only way to find an element is to orbit around it with the mouse. The tools live in the
Geoportal plugin inside GeoLibre.
