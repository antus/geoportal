  - A mapping with JSON expressions tested on a live sample shows the device, time, geometry and measures it would produce before saving.
  - A saved mapping produces the same observations in production as in the test on the sample.
  - A threshold in centimetres on a series declared in metres is converted, not compared raw.
  - A binary payload is decoded by a GeoFlow decoding process selected on the network.
---

Rules assume there is a value to watch, but nothing says how a raw payload becomes a measure with a name, a unit and a time. This is the missing contract: a declared mapping from payload to device, time, geometry and measures, with expressions on the JSON, tested on a live sample before saving, and declared units. The mapping is a document bound to the network, not code, and the test runs the same path as production. For formats a mapping cannot describe (binary, LoRaWAN, proprietary) the escape is a GeoFlow decoding process. Presets for common external IoT systems ship with ready mappings.
