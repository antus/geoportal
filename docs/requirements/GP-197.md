  - A query run by a person on a connection set to propagate identity reaches the warehouse with that person's identity, as the warehouse's own query history shows.
  - Two people with different row policies in the warehouse see different rows from the same layer or widget.
  - A connection without identity propagation keeps using its service account.
---

The token of the person is propagated to the warehouse or federated engine instead of a single service account, so the row and column policies the organization already wrote there keep applying through Geoportal. Without it Geoportal always sees everything, and the organization's security becomes a list of sanitized views maintained by hand. Geoportal's own permissions say who may query; this says what they see when they do. Obtaining a token for the person scoped to an external system (Keycloak token exchange) is a generic capability.
