  - A converted model appears in the catalog with revision, discipline, IFC schema, units, reference system, author and authoring software, and is found by the catalog search.
  - The original IFC file can be downloaded from the model's page by anyone with download permission, and not by others.
  - The model can be shared on its own, without sharing a map that contains it.
  - The size of the source file and of the tileset is counted in the storage used by the organization.
---

A model becomes an entity of the catalog with revision, discipline, IFC schema, units, reference
system, author, authoring software and the source file kept and downloadable, with the same page, tags,
search and sharing as the other resources, and with its size counted against the organization's quota.
Without it a model is a URL inside a map: it cannot be searched, cannot be shared alone, and nobody knows
where it comes from or who added it. A map layer then takes a model as its source instead of a URL and
inherits tree, fields, style, table and popup from it.
