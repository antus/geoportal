  - The data tab of a widget shows the chosen source and part with its type and the number of columns read.
  - The axes of a chart are chosen among the columns read from the source.
  - Reading parameters (row limit, filter, extent, refresh interval, stream buffer) are set per widget under Advanced, and two widgets on the same table can use different ones.
  - A widget without a chosen source says so and offers to choose one.
---

In a dashboard, choosing a table inside a connection already says how it is read, so the protocol list
disappears as the first choice. The data tab shows the chosen source and part with the columns read;
chart axes are chosen among those columns instead of being typed. Under Advanced remain the reading
parameters, which belong to this use of the source, not to the source. A widget without a linked source
says so instead of staying silent.
